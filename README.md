# 📝 C++ Notes App

A fast, lightweight, full-stack notes management application powered by a custom C++ HTTP backend and an interactive Vanilla JS frontend.

## ✨ Features
- **User Authentication:** Login and account registration system.
- **Full CRUD Support:** Create, view, edit, and delete notes dynamically.
- **Search Functionality:** Filter notes instantly by keyword.
- **Theme Support:** Dark/Light mode toggle with preference persistence.
- **Custom Backend:** Built with C++ utilizing RESTful API endpoints and lightweight file storage.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend:** C++ (`httplib` REST API)
- **Database / Storage:** File-based custom database manager (`DatabaseManager`)
